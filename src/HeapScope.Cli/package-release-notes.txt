3.13.2: dump values in logs, by consent.

- heapscope-cli settings --dump-values-in-logs on --yes writes the values HeapScope reads from dumps (field values and
  string text) into its logs, to back up a result in full; off (the default) keeps only their length. Turning it on
  needs --yes; without it the command says what it would do and changes nothing. The logs stay on your machine.
- heapscope-cli settings shows the new setting, and every log says at its start whether it holds dump values.

All release notes: https://github.com/klundt-org/HeapScope/blob/main/RELEASE-NOTES.md
