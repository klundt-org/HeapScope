4.6.0: Right answers.

- inspect says how many objects a detector could not read, and refuses an answer that read none of them, instead of "0 found" (4.6.0).
- Every command says an appsettings.json it cannot read with its file and line, and logs a start that fails (4.6.0).
- A recording whose process stops answering, as in a debugger, ends after a while and says so (4.6.0).
- Struct statics are named by their field in paths and object; the index cache of a dump opened again is rebuilt (4.6.0).
